# Physical AI vs Human Telemetry

This interactive simulation compares the reaction times and stabilization capabilities of human limits (e.g., Max Verstappen) against Physical AI controllers in the Tesla Roadster and SpaceX Falcon 9.

Select the vehicle, adjust the reaction time (200ms for human, 2ms for AI), and simulate a mid-air crosswind to see the telemetry differences.
